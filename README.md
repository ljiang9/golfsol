# golfsol ⛳

终端高尔夫纸牌接龙（Golf Solitaire）。纯标准库，零依赖。

## 玩法

```bash
python -m golfsol            # 交互游玩
python -m golfsol --seed 42  # 固定牌局
python -m golfsol --auto     # 贪心机器人演示
```

- 52 张牌：**35 张在牌桌（5 列 × 7 行）**，17 张在牌堆。
- 每列只有**最底下**的一张牌是"暴露"的，可以走。
- 输入列号 `1-5` 移走该列底牌，`d` 从牌堆摸一张，`q` 退出。
- 只能移走与**废牌堆顶点数相差恰好 1** 的牌（向上或向下均可）。
- 目标：把 35 张牌桌牌全部移走。**得分 = 剩余牌桌牌数**（0 分 = 全胜）。

## 规则细节

- A=1 最小，K=13 最大；**K 和 A 之间没有回绕**（有意选择，符合主流 Golf 规则）。
- 开局废牌堆为空，必须先摸一张。
- 牌堆摸完且无可走牌时终局，按剩余牌数计分。

## 设计取舍

- 贪心机器人选"已移走最少"的列走，保持各列均衡；只是演示用，不是强 AI。
- 行输入模式，每步需回车（纯标准库跨平台取舍）。

## 已知局限

- 无悔棋、无存档、无最佳成绩记录。
- 交互模式需要终端（tty）；管道/脚本场景请用 `--auto`。
- 固定 5×7 布局，不支持 6 列等变体。
